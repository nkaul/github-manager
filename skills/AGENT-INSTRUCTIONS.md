# Agent task preamble

Use the requested skills from this folder or the equivalent installed paths. Read each relevant `SKILL.md` first, then only the supporting references needed for the current deliverable. If a skill is unavailable, use its explicit path; do not invent that it was loaded.

Current user instructions and project authority take precedence over skill examples. Preserve the selected scope, existing approvals, data policy and prior artifacts. Keep current implementation, approved target, measured evidence, reconstructions and proposals distinct. Do not copy GitHub Manager's stack or thresholds into an unrelated project without a reason.

For design: inspect the actual repository, trace the requested user workflow, identify material gaps and dependencies, and make decisions reviewable. Honor a plan-only request; proceed with already-approved implementation when the user has authorized it.

For writing: establish the premise and problem before product vocabulary. Preserve insights while improving the story. Show concrete data through input → operation → output → consequence and keep qualifications close to claims.

For illustrations: inspect a relevant bundled or supplied image, define the content inventory, use semantic objects and a readable visual path, then inspect the final export at its actual intended size. Historical reference-image text is style context, not factual authority.

When composing: settle the evidence and design first, draft the explanation, then illustrate the mechanisms. Review all three against the same facts. Use only available tools; follow tool-specific instructions for image generation, browser operation or publishing. Do not infer paid API calls, live changes, public uploads or destructive cleanup from permission to create a local artifact. Do not introduce a new approval gate for an action already explicitly authorized.

Return the concrete artifacts, what was checked, and material unresolved limitations. Do not claim formatting checks prove usability, model accuracy or reader engagement.
