# Research Shelf

A local paper organizer used by one research group to collect abstracts, review suggested categories and find relevant reading. Current prototype is a Python service with SQLite storage. An authenticated connector can return public and private abstracts. The UI edits folder membership and shows papers without a folder as Unclassified. There is no deployed queue or vector database.

The current code below is a reduced fixture for architecture review, not a production service. No real account or model should be called.
