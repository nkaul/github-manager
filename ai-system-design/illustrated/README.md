# GitHub Manager — illustrated edition

Read [the illustrated article](github-manager-ai-system-design-illustrated.md). It preserves the full technical case study, evidence links, measured results, formulas, caveats and research agenda, with a separate set of user-friendly illustrations.

The illustrations follow the visual language of the original files in `docs/diagrams`: handwritten headings, black pen sketches, recognizable people/documents/robots/database icons, circled steps, flowing arrows and soft marker highlights. They were generated with the built-in Image Generation tool using the original diagrams as style references, then reviewed for technical accuracy and content coverage.
