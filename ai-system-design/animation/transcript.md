# GitHub Manager — two-minute animated overview

AI-generated Cedar narration; calmer delivery. This is an illustrated explanation, not a new application test.

## Your repositories deserve a map.

Your own repositories. Shared projects. Libraries you starred for later. Finding them is easy. Remembering how they fit together is harder. GitHub Manager brings them into one workspace, where you can search, explore, and organize.

## Same technology. Different purpose.

Projects group an initiative. Domains group those projects. Topics describe capabilities, and tags describe technologies. Two repositories can both use Python without belonging to the same project.

## Agree on the vocabulary first.

There are two separate AI jobs. Taxonomy discovery proposes a vocabulary from a collection of repositories. You review and edit it. Classification then works with approved concepts, rather than inventing new labels.

## Keep the sentence that explains why.

Follow our synthetic Orion example. Its README says: patient intake API for the Orion Clinical Platform. Uses FastAPI and Python. We keep that purpose sentence, its evidence reference, and useful phrases.

## A shortlist is not a decision.

Local search retrieves six possible concepts. Some are distractions: Forge shares the word platform, but that doesn't establish a relationship. Retrieval finds possibilities. It doesn't assign them.

## Show the model evidence and boundaries.

The model receives evidence, candidate definitions, instructions, and a response schema. In the saved test, it selected Orion, Web APIs, FastAPI, and Python, citing the purpose sentence. You review those suggestions before accepting them.

## Remember the work. Respect your decisions.

The app remembers completed analysis separately from labels. Removing a project doesn't erase that receipt. Later changes can reconcile locally. A fresh AI analysis remains an explicit choice.

## Useful organization. Your control.

Every model call has a reviewed budget: count, reserve, generate, record. Find the repository you need. Understand why it belongs. Keep the final decision yours.
